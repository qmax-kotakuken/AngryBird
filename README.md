# Angry Bird Clone

Unity 2D の物理演算を使った、スリングショット型ゲームの小規模な再現プロジェクトです。
転職活動用のコードサンプルとして、ゲーム素材よりも入力・物理・状態管理の実装を主眼にしています。

## 開発環境

- Unity 2021.3.2f1
- C# / Rigidbody2D / Collider2D
- シーン: `Assets/Scenes/MainScene.unity`

## 実装内容

- マウスドラッグによる発射方向・強度の決定
- 発射前の予測線と、発射後から最初の衝突までを記録する飛行軌跡
- 最大牽引距離と逆方向への牽引制限
- 鳥との直接衝突と衝突相対速度による敵の撃破
- 黄色い鳥の発射後タップによる一度限りの加速能力
- 黒い鳥の手動爆発、衝突後の色変化と自動爆発
- 敵の登録・解除によるクリア判定
- 次の鳥の生成、ゲーム停止、リスタート
- Inspectorのリストによる鳥の生成順設定

## コード構成

- `Bird.cs`: 入力、照準、飛行軌跡、発射、衝突後のライフサイクル
- `YellowBird.cs`: `Bird`を継承した黄色い鳥の加速能力
- `BlackBird.cs`: `Bird`を継承した黒い鳥の範囲爆発能力
- `Enemy.cs`: 撃破条件と LevelManager への状態通知
- `LevelManager.cs`: 鳥と敵の進行管理、クリア・リスタート

Inspector の値は `[SerializeField]` で公開し、実行時の状態は private に閉じています。
LevelManager は敵を `HashSet` で管理し、同じ敵からの重複通知でカウントが壊れないようにしています。

## 実行方法

1. Unity Hub から Unity 2021.3.2f1 でプロジェクトを開く
2. `Assets/Scenes/MainScene.unity` を開く
3. Play を押す
4. 鳥を左方向へドラッグして離す
